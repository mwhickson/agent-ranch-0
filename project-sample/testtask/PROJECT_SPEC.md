# Sample Project Specification

## Overview

This is a console-based number guessing game.

A random number (integer) between 1 and 100 should be selected for each game round and the user prompted to enter a guess.

A response to the guess will be emitted with an indication that the number was successfully guessed, or was too high, or was too low.

Once the number is guessed, the player will be asked to play again.

Based on user input, either exit or play anther round.

---

## Technical Stack

### Approved
* **Languages & Runtimes:** Python, Bash

### Prohibited
* **Remote Network Access:** Strictly forbidden by default. Remote resources may only be accessed via local network bridges explicitly authorized by the Human Orchestrator.
